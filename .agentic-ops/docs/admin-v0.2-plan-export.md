# PLAN-EIT-ADMIN-V02-AGENTIC-OPS

Preset: `cms_wordpress_elementor_low_code`

## Objective
Adapt the Elementor Implementation Toolkit Admin V0.2 frame-first plan into an Agentic Ops operational contract that can be inspected, initialized in overlay mode, validated, executed, snapshotted, exported, and handed off through the Agentic Ops MCP.

## Scope
- Use the WordPress workspace as an Agentic Ops overlay target without replacing AGENTS.md.
- Keep the Admin V0.2 source of truth, frame implementation plan, canonical icons, and QA evidence as the source inputs.
- Use cms_wordpress_elementor_low_code as the primary preset and visual_front_end_first as the secondary validation preset.
- Turn the first implementation slice into ordered phases, tasks, tests, decisions, and handoff context.
- Limit code execution scope to the Elementor Implementation Toolkit admin UI/config state when implementation begins.
- Use MCP validation before treating any plan, task, phase, test, or handoff as executable.

## Out Of Scope
- Do not edit WordPress core.
- Do not replace existing AGENTS.md instructions.
- Do not initialize .agentic-ops/ automatically as part of this documentation adaptation.
- Do not build runtime filtering, listing, grid rendering, or frontend token export in Admin V0.2.
- Do not claim deep WooCommerce, Simple Budget, JetEngine, Elementor Pro, or Elementor Globals runtime integration until separately researched and implemented.
- Do not use production WordPress access or destructive CLI flags.
