# Implementation Package — Single Service stress test

## Test job

Prove that the shared Single Service template survives its longest title and a dense implementation-document evidence set without enlarging the masthead, creating a card wall or losing visual hierarchy.

## Protected template invariants

- Same section order and geometry as Commercial Layout and Interior Concept.
- Compact photo-free masthead with orange service code.
- Primary evidence directly below the masthead.
- Flat outcomes and process bands, asymmetric deliverables, one related case, shared CTA/footer.
- Continuous rails, square geometry, restrained cyan, zero UI shadows and fixed media boxes.
