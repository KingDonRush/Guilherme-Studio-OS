Subplan: `SUBPLAN-FC-AUDIT-RADIO`

Status: audit complete, implementation not started.

## Purpose

Audit radio filters as a single-select choice component.

Radio is not "checkbox but round". It communicates mutual exclusion: one value
from a group is active, and the user needs an obvious way to return to no
selection when the filter is optional.

## Current Behavior Contract

- Only one option in the radio group can be selected.
- JS pushes a single scalar value for radio.
- Server resolver matches one token against the item value.
- Reset clears all radios.
- There is no "All" radio generated by default.

## Mechanical Bugs And Risks

1. Optional radio lacks an in-component clear affordance.
   - Users can reset the whole controller, but cannot clear just one radio group
     unless active chips are visible.

2. Radio and checkbox share nearly identical styling.
   - The current pill treatment can blur the difference between single and
     multiple choice.

3. Segmented-control mode is not explicit.
   - Some radio groups should become segmented controls.
   - Others should remain ordinary radio rows.

4. Focus and selected state need a mutual-exclusion cue.
   - A selected radio should make other options feel available but inactive.

## Product Controls To Add

Immediate:

- radio layout: list, wrapped row, segmented;
- show native radio: on/off;
- option equal width for segmented mode;
- selected indicator style;
- focus ring;
- clear option label such as "All".

Later:

- icon per option;
- description text;
- default selected value;
- disable individual options;
- keyboard arrow-key refinement if custom segmented mode hides native radios.

## QA Scenario

Guilherme should test:

1. Radio with 3 options and no active option.
2. Select one option and confirm the selected state is unmistakable.
3. Try to deselect only that group; decide whether an "All" option is needed.
4. Test list mode versus segmented visual direction.
5. Use keyboard tab and arrow/space behavior.
6. Verify reset clears radio state.
7. On mobile, confirm segmented mode does not squeeze labels.

Pass criteria:

- single-select semantics are visible;
- there is a clean path back to "no radio filter";
- radio does not look like a multi-select chip set unless intentionally styled.
