# Social Distribution Assets

Use this folder for social post crops and campaign variants.

Recommended naming:

```text
<project>-<surface>-<ratio>-v<n>.webp
```

Examples:

- `simple-budget-case-linkedin-1200x1200-v1.webp`
- `simple-budget-flow-instagram-1080x1350-v1.webp`

Social assets may adapt the composition, but they must not introduce claims,
features, logos, or UI states that are absent from the project evidence.
