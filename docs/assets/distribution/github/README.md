# GitHub Distribution Assets

Use one folder per public repository:

```text
docs/assets/distribution/github/<repo-slug>/
  readme-hero.webp
  readme-flow-01.webp
  readme-flow-02.webp
  screenshot-editor.webp
  screenshot-frontend.webp
  social-preview.webp
```

For plugin repositories, prefer assets that prove behavior:

- real editor screenshots;
- frontend interaction screenshots;
- short flow frames;
- architecture or capability diagrams only when they clarify a real decision.

Do not use generated images to claim a plugin feature that was not verified in
the plugin source or runtime.
