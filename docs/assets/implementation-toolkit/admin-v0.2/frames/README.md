# Implementation Toolkit Admin V0.2 Frames
These frames were generated as visual source material for the Elementor
Implementation Toolkit admin architecture work.

They are saved here because generated images that become practical direction
must not remain only in the Codex/imagegen cache.

## Files

- `contact-sheet.png`: numbered overview of the saved frames.
- `frame-01.png` through `frame-28.png`: source PNG frames copied from the
  generation cache.

## Ordering

The frame numbers match the contact sheet order. `frame-01.png` is the most
recent generated frame in the recovered batch, and `frame-28.png` is the oldest
frame in that batch.

The names are intentionally numbered because this batch was not labeled at
generation time. Future generated UI frames should be saved immediately with
semantic names when the state is known, for example:

- `filters-01-overview.png`
- `filters-02-provider-selected.png`
- `cpt-03-meta-field-selected.png`
- `integrations-04-preview-modal.png`
