The recommended `shadow-v2` PNGs keep a soft semi-transparent grounding shadow
inside the alpha canvas. The original `v1` files remain available as clean
shadowless cutouts.

Matching green-screen sources with shadows are preserved as
`chroma/*-chroma-shadow-v2.png`. The original shadowless chroma files also
remain available.

## Build natively

Do not replace these elements with raster assets:

- Elementor editor panels and plugin control screenshots;
- hero comparison diagram, connectors, cards, and lock symbol;
- buttons, checks, arrows, section numbers, and technical icons;
- borders, backgrounds, grid lines, and separators.

Use the existing portfolio portrait and technical background assets. Capture
the Elementor panels from the real plugin environment after the case layout is
assembled.
