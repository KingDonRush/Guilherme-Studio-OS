# Simple Budget Case Icons

## Custom asset

- `wordpress/simple-budget-plugin-rigid-page-locked-layout-v3.webp`
  - Optimized WordPress production asset.
  - WordPress attachment ID: `460`.
- `png-transparent/rigid-plugin-page-imagegen-v3.png`
  - Compound locked-page pictogram used in the hero comparison.
  - High-resolution imagegen restoration constrained by the approved case
    mockup and its vertical composition.
  - Pixel-tight alpha bounds verified on all four edges.
  - This is the only icon/illustration in the approved case that is not already
    available through Elementor, Font Awesome, WordPress, or the portfolio
    asset library.
- `chroma/rigid-plugin-page-imagegen-chroma-v3.png`
  - Green-screen source preserved for future extraction adjustments.

## Font Awesome fallback

The installed Elementor build includes Font Awesome 5 Solid. Use
`fas fa-paper-plane` for the server-side handoff icon. The other mapped
symbols are already covered by Eicons.
