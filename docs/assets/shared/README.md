# Shared Assets

Reusable cross-project assets live here.

Use this folder for assets that should not belong to a single case:

- `identity/`: Guilherme profile assets, author marks, reusable badge material.
- `icons/`: reusable icon packs or icon sources.
- `textures/`: grain, lighting, paper, glow, depth, transparent overlays.
- `backgrounds/`: reusable background plates or section atmospheres.

Do not move existing project-specific assets here unless they are genuinely
shared across more than one surface.
