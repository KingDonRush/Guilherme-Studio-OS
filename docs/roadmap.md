# Roadmap

## Phase 1: Foundation

- Create agentic structure.
- Initialize root git.
- Set up local WordPress environment.
- Install Elementor.
- Clone plugin repositories.
- Install useful MCP packages in `operations/tools/mcp/` and document usage.

## Phase 2: Plugin Audit

- Audit `3d-viewer-to-elementor`.
- Audit `simple-budget-plugin`.
- Create issue backlog for each plugin.
- Identify quick wins and risky areas.

## Phase 3: Plugin Polish

- Stabilize Elementor editor behavior for 3D viewer.
- Simplify and professionalize optimization logic.
- Add useful controls and docs.
- Make budget plugin destinations configurable.
- Decide whether budget plugin needs widget mode.

## Phase 4: Portfolio Build

- Create portfolio copy in English.
- Create case studies.
- Build portfolio WordPress site.
- Capture screenshots and demos.
- Add public links and GitHub polish.

## Phase 5: Market Strategy

- Collect friend reports.
- Research international job/freelance channels.
- Create outreach assets.
- Iterate positioning based on response.
