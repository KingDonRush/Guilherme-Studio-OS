# Assumptions

- The primary portfolio language for recruiters and READMEs should be English,
  even if internal planning can remain Portuguese.
- The user wants international roles involving WordPress, Elementor, custom
  plugins, and design implementation.
- GitHub repositories are public enough to clone without authenticated `gh`.
- Elementor Free is enough for the first local development environment; Pro can
  be added later if the user has a license.
